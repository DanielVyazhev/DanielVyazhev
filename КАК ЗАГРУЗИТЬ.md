# Одна папка для обоих репозиториев

Загрузите всё содержимое этой папки в оба репозитория: `DanielVyazhev` и `DanielVyazhev.github.io`.

- В `DanielVyazhev` профиль берёт `README.md` и `assets/`, а `index.html` просто лежит рядом и ничего не ломает.
- В `DanielVyazhev.github.io` сайт берёт `index.html`, `avatar-src.png` и `data/`, а `README.md` станет описанием репозитория.

Как заменить: в репозитории удалите старые файлы и папку `assets/`, затем Add file → Upload files → перетащите всё отсюда → Commit.

`avatar.png` — для Settings → Public profile → Profile picture.
